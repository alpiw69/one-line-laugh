## What this is

One funny line, a single sentence of at most 200 characters:

> I asked my AI assistant to be more human, so it started ignoring my messages too.

## How it works

`main.py` (Python 3.13, no network, deterministic) writes the joke to `/output/entry.txt`.

```bash
python3 main.py
```
